# ⏰ Modern Digital Clock

A modern and responsive digital clock built using **HTML, CSS, and JavaScript**.

This project combines a premium glassmorphism design with real-time JavaScript functionality to create a stylish and fully responsive digital clock.

## ✨ Features

* 🕐 Real-time digital clock
* ⏱️ Hours, minutes, and seconds
* 🌙 12-hour AM/PM format
* 📅 Dynamic date
* 🌤️ Dynamic day indicator
* 💎 Glassmorphism UI
* ✨ Neon glow effects
* 💫 Smooth animations
* 📱 Fully responsive design
* ⚡ Updates automatically every second
* ❌ No external JavaScript libraries

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
